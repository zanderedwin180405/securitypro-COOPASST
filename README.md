# 🚀 Proyecto HTML/JS/CSS SENA SST & COPASST

Esta carpeta **`proyyecto html`** contiene el proyecto completo en **HTML5 puro, CSS (Tailwind CDN) y JavaScript vanila (sin Node ni compiladores)** listo para ser abierto en cualquier navegador o subirse a **GitHub Pages**.

---

## 📁 Archivos incluidos

- `index.html`: Página principal con toda la estructura responsiva, módulos, barra lateral, cabecera y diálogos modales.
- `styles.css`: Estilos personalizados, animaciones y barras de desplazamiento.
- `app.js`: Lógica de navegación, geolocalización GPS en tiempo real, eliminación de miembros COPASST no presentes, captura de foto y conexión con Supabase.
- `404.html`: Copia para manejo de rutas de GitHub.
- `.nojekyll`: Archivo para GitHub Pages.

---

## 💻 ¿Cómo abrirlo localmente?

Simplemente haz doble clic sobre el archivo `index.html` en tu explorador de archivos para abrirlo en Chrome, Edge o Firefox. No necesitas instalar nada.

---

## 🌐 ¿Cómo subirlo a GitHub Pages?

1. Crea un nuevo repositorio en GitHub: [https://github.com/new](https://github.com/new).
2. Sube todos los archivos que están dentro de la carpeta **`proyyecto html`**.
3. En GitHub, ve a **Settings** -> **Pages**, selecciona la rama `main` y guarda.
